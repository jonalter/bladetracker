    <div class="support-card" id="tips">
      <h4>Tips for staying dialed in</h4>
      <ul class="list-tips">
        <li><strong>Save the tech/shop</strong> on every sharpening so you can spot patterns.</li>
        <li><strong>Use performance notes</strong> after each session for quick memory of how the hollow felt.</li>
        <li><strong>Create a “tournament set”</strong> with a different hollow and swap it in/out as you need.</li>
        <li><strong>Retire blades</strong> instead of deleting them to preserve history.</li>
      </ul>
    </div>
